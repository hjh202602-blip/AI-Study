# 보물지도 (웹사이트)

공부 노트(.md)를 보물지도 한 장으로 보여 주는 사이트. 전체 지도 → 섬 → 자세히, 확대할수록 더 많은 표시가 보인다. 노트 내용은 저장소의 `README.md` 목차를 읽어서 **자동으로** 지도에 올라간다.

## 새 내용 추가하기

1. `neural-networks/` 에 .md 파일을 쓴다.
2. 루트 `README.md` 목차에 한 줄 추가한다.

```md
### 02. ANN                                  ← 섬(챕터) 하나
 - [01. ANN](./neural-networks/02-00ANN.md)   ← 핀 하나 (순서대로 길이 이어짐)
 > [01+. 더 보기](./neural-networks/x.md)     ← 앞 핀에 딸린 곁가지 핀
#### 실습 예제                                ← 이 아래 링크는 섬의 실습 파일 목록
* [예제](./neural-networks/practice/x.py)
```

푸시하면 끝. 본문이 거의 비어 있는 노트는 지도에 `?` (아직 안 쓴 섬)으로 보이다가, 내용을 채우면 핀으로 바뀐다.

## 새 지도(개념 묶음) 추가하기

지도 한 장 = 목차 파일 하나. 지도 제목은 섬 이름을 이어서 자동으로 만든다 (예: `파이썬 × 퍼셉트론 × 신경망`).

1. 새 목차 파일을 만든다 (예: `cnn/README.md`, 형식은 위와 같음).
2. `docs/js/config.js` 의 `maps` 에 한 줄 추가한다.

```js
{ id: 'cnn', source: 'cnn/README.md', subtitle: '합성곱 신경망 공부 노트' },
```

그러면 화면 맨 위 두루마리 줄에 나타나고, 누르면 지금 지도는 말리고 새 지도가 펼쳐진다.
지금 있는 `빈 지도 1~5` (`placeholder: true`) 는 테스트용이라 새 지도를 넣으면 지워도 된다.

## (선택) 꾸미기 — `docs/js/config.js`

섬·지점 꾸미기는 각 지도의 `regions`, `nodes` 안에 적는다.


- `regions['02']` : 섬 이름, 영어 부제, 설명
- `nodes['파일이름']` : 지도에 보일 이름, 한 줄 요약, 붙일 시각화(`widgets`), 표시 종류(`mark`)
  - `clue` 단서 🔑 (핵심 개념에만) · `area` 구역 (곁가지까지 점선으로 묶음) · `flag` 표지 (기본) · `camp` 야영지 (곁가지 기본)
  - 본문이 비어 있는 노트는 자동으로 `?` 미개척

## 섬 모양

섬은 `ellipse`(타원) · `T` · `ㅗ` · `U` · `L` · `C` 중 하나. 각 지도의 `regions['00'].shape` 로 고르고, 없으면 순서대로 돌아가며 쓴다.
지점들은 섬 모양을 따라 순서대로 놓인다. 지점이 많으면 섬이 그만큼 커진다.
섬 위치는 지도마다 무작위(늘 같은 배치)이고, 보물길이 README 순서대로 섬을 잇는다.
오른쪽 아래 **나침반(다음 섬 방문하기)** 을 누르면 마지막으로 들른 섬의 다음 섬으로 간다. 처음이면 첫 섬.

## ✕ 보물 문제

- **섬마다 ✕ 보물**: `quiz.questions` 의 각 문제는 `about`(관련 지점)이 속한 섬의 ✕ 에 자동으로 들어간다.
- **마지막 보물섬**: 지도 맨 끝(가로 화면은 오른쪽, 세로 화면은 아래)에 보물만 있는 섬이 생기고, `quiz.final` 문제(단원 최종 퀴즈)가 나온다.
- 다 맞히면 ✕ 가 보물 상자로 바뀐다. 최종 보상은 `quiz.reward` 에 적는다 (아직 비어 있음).

## (선택) 시각화 추가 — `docs/js/widgets.js`

```js
W.myWidget = (box) => { /* box 안에 그리기 */ };
```

`config.js` 의 `widgets: ['myWidget']` 에 넣거나, .md 본문 원하는 자리에 `<!-- widget: myWidget -->` 를 적으면 그 자리에 나온다. (깃허브에서 볼 때는 주석이라 안 보임)

지금 있는 시각화: `sinPlot` `perceptron` `gateFit` `gateBoard` `numpyStep` `boundary` `xorNet`

## 코드 실행

노트 속 ` ```py ` 코드 블록에는 자동으로 **▶ 실행 / ✎ 고치기** 버튼이 붙는다 (브라우저 안에서 진짜 파이썬이 돈다).
함수를 정의한 코드를 실행하면 `AND(1, 1)` 같은 호출 버튼과 `>>>` 입력칸이 생긴다.
README의 `#### 실습 예제` .py 파일도 섬 패널에서 바로 실행할 수 있다. `input()`은 코드 아래 '입력값' 칸의 값을 차례로 쓴다.

**안전장치** — 보는 사람이 어떤 코드를 적어도 페이지가 망가지지 않게:
- 파이썬은 페이지와 분리된 작업 공간(Web Worker)에서 돌아서 화면·저장소·다른 탭에 손댈 수 없다.
- 8초(numpy·matplotlib 첫 실행은 30초)가 지나면 자동으로 멈추고 새로 켠다. ■ 멈춤 버튼도 있다.
- 출력이 너무 많으면 잘라 내고, 결과는 글자로만 붙인다(HTML 로 해석하지 않음).
- 그래프 식 칸은 x, 숫자, 연산자, sin·cos 같은 정해진 이름만 받는다.
